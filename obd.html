03 — OBD

OBD
クルマが書く「体調日記」

OBD(オービーディー)は、車が自分自身の調子をチェックし、異常があれば記録しておくしくみです。整備士はこの記録を専用の機械で読み出して、故障の場所を探します。2024年10月からは、日本の車検でもこの記録が調べられるようになりました。

01 — HOW IT WORKS

ECUが、自分で自分を見張っている。

車のECUは、運転を制御しながら同時に「センサーの値がおかしくないか」「指示どおりに部品が動いているか」をチェックしています。異常を見つけると、

  1. メーターの警告灯を点けて運転者に知らせる
  2. 何が起きたかを故障コードとして記録する

という2つのことを行います。この機能全体をOBDと呼びます。

ひとことで言うと

OBD = 車に内蔵された「自己診断機能」と、その結果を外から読み出すための「共通の決まり」。

よくある誤解

「OBD2」「OBD-II」は、OBDの第2世代の規格のこと。今の車で「OBD」といえば、ふつうはこの第2世代を指します。

02 — HISTORY

もともとは「排ガス」を見張るため。

OBDは、アメリカやヨーロッパで、排出ガスに関係する装置の故障を見逃さないための仕組みとして義務化されました。日本では、自動ブレーキなどの先進安全技術が広く普及したことを受けて、車検での活用が始まりました。

  • 1996

    アメリカで、販売されるすべての乗用車・小型トラックにOBD-IIが義務化。

  • 2001 / 2004

    EU(ヨーロッパ連合)で、ガソリン車(2001年)、ディーゼル車(2004年)に欧州版OBDが義務化。

  • 2023.10

    日本で車検のOBD検査の「プレ運用(慣らし期間)」開始。

  • 2024.10

    日本で国産車のOBD検査が本格スタート。

  • 2025.10

    輸入車のOBD検査がスタート。

03 — CONNECTOR

運転席の足元にある、16本の穴。

OBD-II対応の車には、形と各ピン(穴)の役割が決められた16ピンのコネクターがあり、ふつうはハンドルの下あたりにあります。ピンに触れると役割が表示されます(番号が書かれていないピンは、メーカーが自由に使えるピンです)。

ピンに触れてみましょう。とくに大事なのは4・5番(アース)、6・14番(CAN通信)、16番(バッテリー電源)です。
ポイント

16番には常にバッテリーの電気が来ています。金属の工具などでピン同士をつなげてしまう(ショートさせる)と危険なので、むやみに触らないようにしましょう。

04 — TROUBLE CODE

故障コードを、読み解いてみよう。

故障コードは「英字1文字+数字4ケタ」。それぞれのケタに意味があります。例を選ぶか、自分で入力してみてください。

※ 2ケタ目が「1」のコードはメーカー独自の意味を持つため、正確な内容は各メーカーの整備書で確認します。ここでは共通ルールに基づく大まかな意味を表示しています。

05 — INSPECTION

2024年から始まった「OBD検査」とは。

これまでの車検は、ブレーキの効きや排ガスなど「機械としての状態」が中心でした。警告灯が点いていても、基準を満たしていれば合格になることがありました。OBD検査では、車検時に専用のスキャンツールをつなぎ、決められた重要な故障コードが記録されていないかを確認します。

なぜ

導入された理由

自動ブレーキなどの先進安全技術は事故を減らす一方、故障すると誤作動して事故につながるおそれがあるため。電子装置の故障を車検で見逃さないことが目的です。

対象

対象になる車

国産車:2021年10月以降に新しく型式指定を受けた新型車(フルモデルチェンジ車など)。
輸入車:2022年以降の新型車。
それ以前から作られている車は対象外です。

開始

始まった時期

国産車:2024年10月1日から。
輸入車:2025年10月1日から。

COLUMN

「ODI」は、まったく別の言葉。

OBDと1文字ちがいの「ODI」は、車ではなくパソコンのネットワークの用語です。1989年にアップルとノベルという会社が共同で発表した、ネットワークカード(LANにつなぐ部品)とソフトの間の受け渡しの決まりです。

マイクロソフトなどが作った「NDIS」という規格と同じ役割を持ち、通信を7つの階層で整理したOSI参照モデルの第2層(データリンク層)で働きます。現在はほとんど使われていない、歴史上の規格です。

ネットワークのハブのページで、ネットワークの基本もあわせて学べます。

OBDODI
分野自動車パソコンのネットワーク
意味車載式故障診断ネットワークカード用の接続ルール

06 — HOW TO USE

スキャンツールのつなぎ方(基本の流れ)。

機器によって細かい手順は違います。必ず使う機器の取扱説明書を確認してください。

  1. エンジンを止め、イグニッション(電源)をOFFにする電源が入ったまま抜き差しすると、機器や車に負担がかかることがあります。
  2. 運転席の足元でOBDコネクターを探す多くはハンドルの下付近。カバーの中に隠れていることもあります。
  3. 向きを確かめて、まっすぐ奥まで差し込む台形の形なので、逆向きには入りません。無理に押し込まないこと。
  4. イグニッションをONにして、ツールの画面に従う故障コードを読み出し、内容を必ず記録してから次の作業に進みます。
  5. 原因を直してからコードを消す原因が残ったまま消しても、また記録されて警告灯が点きます。
